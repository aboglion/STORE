# PWA — פתרון התקנה אמיתי ל-Firefox ול-iPhone

מסמך זה עונה על השאלה: "האם יש ספרייה או דרך שכן פותרת התקנת PWA ב-Firefox וב-iPhone?"

## 1. האמת הטכנית הקשיחה (מה שאי אפשר לעקוף)

### 1.1 iPhone / iPad (כל הדפדפנים)
- אפל **אינה תומכת** ב-`beforeinstallprompt` כלל. אין API, אין אירוע, אין ספרייה שיכולה להפעיל התקנה יזומה ב-iOS Safari.
- כל הדפדפנים ב-iOS (Safari, Chrome, Firefox, Edge) משתמשים במנוע WebKit — כולם כפופים לאותה מגבלה.
- **הדרך היחידה** להוסיף PWA למסך הבית ב-iOS ידנית: שיתוף (Share) → "הוסף למסך הבית" (Add to Home Screen).
- כל ספרייה שטוענת אחרת פשוט מציגה מדריך/חץ (mock) — היא לא מתקינה. זה לא באג באתר, זו מדיניות אבטחה של אפל.

### 1.2 Firefox (אנדרואיד ומחשב)
- Firefox **אינו תומך** ב-`beforeinstallprompt`. הוא בחר שלא ליישם את הממשק.
- הדרך היחידה ב-Firefox ידנית: תפריט (⋮) → "הוסף למסך הבית" / "Install".
- גם כאן — אין ספרייה שיכולה להתגבר על זה.

> **מסקנה חדה:** שום ספריית JavaScript לא יכולה ליצור את חלון ההתקנה הרשמי של מערכת ההפעלה היכן שהדפדפן לא מספק אותו. זה בלתי אפשרי מבחינה טכנית, בכל פלטפורמה — לכל היותר אפשר להציג מדריך יפה.

## 2. הפתרון הנכון באמת (מה שחנויות מקצועיות עושות)

הדרך היחידה להבטיח שמשתמש ב-Firefox או ב-iPhone יקבל "אפליקציה אמיתית" היא **לא** להילחם בדפדפן — אלא **לארוז את ה-PWA כאפליקציה אמיתית למכשיר**.

### 2.1 אנדרואיד — APK/AAB אמיתי (עוקף את Firefox לגמרי)
- **PWABuilder (מיקרוסופט)** — https://www.pwabuilder.com/
  - מזין כתובת האתר → מייצר **APK/AAB אמיתי** באמצעות Trusted Web Activity (TWA).
  - את ה-APK אפשר לפרסם ב-**Google Play** — ואז משתמשי Firefox פשוט מתקינים מהחנות.
  - אפשר גם להוריד APK ישירות ולשלוח ללקוחות (sideload).
- **Bubblewrap CLI (גוגל)** — אותה טכנולוגיה משורת הפקודה בתוך הפרויקט.
- **Capacitor (Ionic)** — אריזה מלאה לאפליקציית אנדרואיד/תפוח אמיתית.

### 2.2 iPhone — App Store (הדרך החוקית היחידה)
- בישראל (לא EU) **אין** sideload באייפון — לא ניתן להתקין APK/ipa מחוץ לחנות.
- הדרך היחידה: **לפרסם אפליקציית wrapper ל-App Store**:
  - PWABuilder מספק פרויקט iOS (WKWebView wrapper) שמעלים ל-App Store Connect.
  - Capacitor — פיתוח native מלא לפרסום ב-App Store.
- עד שעושים זאת — ב-iPhone הפתרון היחיד בינתיים נשאר "הוסף למסך הבית" הידני (המדריך הקיים).

## 3. ספריות ש"משפרות חוויית מדריך" (לא מתקינות, אבל שוות)

למי שלא רוצה פרסום בחנות, הספריות הטובות ביותר לחוויית מדריך אלגנטית:

| ספרייה | מה היא עושה | הערה |
|---|---|---|
| **[@khmyznikov/pwa-install](https://www.npmjs.com/package/@khmyznikov/pwa-install)** | Web Component שמנהל `beforeinstallprompt` (Chrome/Edge) + מדריך iOS מובנה | הפתרון המודרני המומלץ, קל לשילוב |
| **[a2hs.js](https://github.com/cferdinandi/a2hs)** | מדריך "Add to Home Screen" ל-iOS עם חץ מונפש ומסוגנן | קלאסיקה ותיקה, קלה במיוחד |
| **[use-pwa-install](https://www.npmjs.com/package/use-pwa-install)** | React hook שמנקה את ניהול `beforeinstallprompt` | מתאים ל-React |

אלה משפרים את חוויית המשתמש (המדריך) — אבל **לא** פותרים את הליבה: התקנה אמיתית ב-Firefox/iOS.

## 4. החלטה מומלצת

### מסלול A — הכי נכון לטווח הארוך (פרסום בחנות)
1. **PWABuilder**: ייצור APK/AAB לאנדרואיד → פרסום ב-Google Play (פתרון מלא ל-Firefox).
2. **PWABuilder / Capacitor** → פרסום ב-App Store (פתרון מלא ל-iPhone).
3. באתר: כפתור "הורד מהחנות" שמזהה פלטפורמה ומפנה ל-Play/App Store, ורק כבסיס ל-PWA בדפדפן.

### מסלול B — מהיר בלי חנות (חלקית)
1. הוספת **קישור הורדת APK** (ש-PWABuilder בנה) בדף: משתמשי אנדרואיד (כולל Firefox) מתקינים APK אמיתי.
2. שילוב **@khmyznikov/pwa-install** או **a2hs.js** לחוויית מדריך דינמית יותר.
3. iPhone נשאר על "הוסף למסך הבית" עד לפרסום ב-App Store.

### מסלול C — מינימלי (מה שכבר קיים)
הדיאלוג הנוכחי המובנה בפרויקט (זיהוי פלטפורמה + שלבים + הערות ל-Firefox/iOS) הוא כבר מקיף וטוב. נשאר רק להשלים את מסלול A/B להשגת התקנה "אמיתית".

## 5. ההטמעה שנבחרה בפועל (best-in-browser UX)

לאור מגבלות הדפדפן, הטמענו את חוויית ה-PWA הטובה ביותר שאפשר בתוך דפדפן — הכוללת:

1. **Android/Chrome/Edge**: ניסיון prompt רשמי של הדפדפן (`beforeinstallprompt`) — חלון התקנה אמיתי.
2. **iOS — שני שלבים ("Coach" מונפש):**
   - שלב 1: מסך פתיחה המדמה את **שורת הדפדפן התחתונה של Safari** עם **כפתור שיתוף פועם (pulse)** שמתבלט ומפנה את העין בדיוק למקום הנכון + חץ יורד.
   - שלב 2: הצעדים הממוספרים (שיתוף → הוסף למסך הבית → הוסף).
   - השלב הראשון מוצג פעם אחת בלבד ל-session (שמירה ב-`sessionStorage`), כדי לא להטריד שוב.
   - הערת אזהרה צהובה: לעדיף ספארי.
3. **Android/Firefox**: הוראות מדויקות לתפריט (⋮) → "הוסף למסך הבית" + **כפתור "פתח ב-Chrome"** (מנסה `intent://` ומעתיק את הקישור לגיבוי), כך שמשתמש יכול לעבור לדפדפן שתומך בהתקנה אוטומטית.
4. **מחשב**: סמל התקנה בשורת הכתובת + תזכורת.

קבצים ששונו:
- `components/pwa/install-prompt.tsx` — כל הלוגיקה + דיאלוג ה-Coach.
- `messages/he.json`, `messages/ar.json` — מפתחות תרגום חדשים.

**השלב הבא המומלץ (מחוץ לדפדפן):** ייצור APK/AAB אמיתי דרך PWABuilder ופרסום ב-Google Play, ופרסום wrapper ל-App Store.

## 6. סיכום כנות
- **אין ספרייה ש"מתקינה" ב-Firefox או ב-iPhone** — זו מגבלת דפדפן מהותית.
- בתוך הדפדפן השגנו את המקסימום: המדריך המונפש והמדויק ביותר שמבטיח שהמשתמש יסיים את ההתקנה בהצלחה.
- הפתרון ה"אמיתי" היחיד ליישום מלא: **לארוז את האתר כאפליקציה אמיתית** (Play Store ל-Android, App Store ל-iOS).
